## Opificium has moved out

**The maker's bench is its own program now**, with its own entry in the
launcher. Install it there and it updates on its own schedule, the same
as any game on the shelf.

That is the whole of this build. The bench no longer ships inside Divus
Factus and the title screen's Opificium button is gone — a door onto a
program the game no longer carries is worse than no door.

Nothing you have made is affected. Every building, every clip, the
palette and the six bodies stay exactly where they were; the game reads
them from the same place it always has. What changed is only where the
program that draws them comes from.

**Why it moved.** Opificium was never really part of this game — it
shared no code with it, only files. Standing on its own means the next
Baz Studios game can use the same bench without carrying Divus Factus
around with it. It works on *projects* now: one game's own folder of
palette, bodies, templates and work. Divus Factus is the first.

The Windows download is smaller for it.
